# johnbillion/action-wordpress-plugin-attestation

Generates an attestation for the build provenance of a plugin published on the wordpress.org plugin directory

Hardened by [Chainguard](https://www.chainguard.dev) from the upstream action at [https://github.com/johnbillion/action-wordpress-plugin-attestation](https://github.com/johnbillion/action-wordpress-plugin-attestation).
